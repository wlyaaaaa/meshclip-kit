# 两台电脑的剪贴板同步

1. 这是什么：让两台不同网络的 Windows 电脑共享复制的文字、互传文件；安卓平板尚未完成。
2. 我怎么用：先让 AI 在两台电脑上配置并完成配对，日常双击 `MeshClip控制中心.vbs` 查看状态或暂停自动恢复。
3. 怎么知道它正常：在两台电脑上分别复制文字、传一个文件，确认另一台能收到且内容一致。
4. 坏了怎么提醒我：控制中心会显示运行和待恢复状态，没有自动提醒，出问题直接跟 AI 说。
5. 让 AI 做什么：检查连接、修复同步或恢复配置，保留已有配对和其他设备的设置。

安装见 [Windows 说明](docs/WINDOWS.md)，故障处理见 [排障说明](docs/TROUBLESHOOTING.md)，AI 维护规则见 [AGENTS.md](AGENTS.md)。
